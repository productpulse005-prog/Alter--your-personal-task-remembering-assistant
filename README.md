# Alter — Your Second Mind 🧠

Alter helps you remember important things, manage daily tasks and groceries, and share responsibilities with family.

### Features
- Add tasks by typing or voice
- Set reminders and alarms
- Save and find personal memories
- Manage grocery lists
- Connect Google Calendar and Gmail (invited users only)
- Share tasks with family

### Tech Stack
Expo, React Native, FastAPI, MongoDB, Gemini AI and Google APIs.

### Current Status
Alter is an early MVP/private beta. Some features may be limited or buggy. AI chat usage is currently limited.

### Privacy
Alter is designed to answer using your personal information. Google sync uses read-only access. Avoid storing passwords, OTPs or API keys.

### Project Docs
Check the `docs/` folder for the PRD, architecture, system prompts, guardrails and security documentation.

**The goal:** Less mental load, better organisation and more peace of mind. 💜
